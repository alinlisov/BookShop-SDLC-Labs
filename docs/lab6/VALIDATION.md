## Нефункціональні вимоги

| ID | Критерій | Факт із попередніх перевірок | Оцінка |
|---|---|---|---|
| NFR-1.1 | Сторінка й пошук ≤2 с | 86 і 102 мс для перевірених сторінок. Час реакції пошуку окремо не зафіксований | Частково підтверджено |
| NFR-1.2 | 100 одночасних користувачів | Locust: 8501 запитів, 0 помилок; середній час відповіді ≈7 мс для GET | Виконано для перевіреного локального навантаження |
| NFR-2.1 | Увесь клієнт-серверний обмін HTTPS | GitHub Pages має HTTPS, але робочий локальний FastAPI на HTTP | Не підтверджено в локальній архітектурі |
| NFR-2.2 | AES-256 для email, телефону, адреси | AES-256-GCM у коді; тести шифрування та цілісності | Підтверджується тестами, перевірити БД |
| NFR-3.1 | Uptime ≥99,5% на місяць | Тривалого моніторингу немає | Не підтверджено |
| NFR-3.2 | Обробка помилкових даних | Ручна перевірка форм пройдена | Підтверджено для перевірених сценаріїв |
| NFR-4.1 | Адаптивність від 320 px | Ручно перевірено в №5 | Підтверджено для перевірених ширин |
| NFR-4.2 | Chrome, Firefox, Safari, Edge | Потрібно перевірити доступні браузери, інші позначити як не протестовані | Не підтверджено повністю |
| NFR-4.3 | Hover для кнопок і карток | Потрібні докази з UI | Потребує підтвердження |

**Висновок валідації:** не змішувати «функцію реалізовано» з «вимогу виміряно і доведено». Для локального навчального прототипу збережи чесний перелік обмежень: HTTPS, місячний uptime і повне кросбраузерне тестування.

## Рекомендації (Етап 6)

1. Для публічної роботи — розгорнути FastAPI за HTTPS, змінити sessionStorage JWT на захищені cookie та додати CSRF-захист.
2. Для NFR-3.1 — додати безперервний моніторинг доступності протягом місяця.
3. Для NFR-4.2 — перевірити сайт у Firefox, Edge, Safari; зберегти протокол тестування.
4. Для FR-5.2 — підтвердити хронологічність відгуків на інтерфейсі.
5. Для тестового покриття — додати перевірки непокритих гілок (`app/routers/*`, помилкові вхідні дані, конфлікти), не дублюючи чинні тести.
6. Для репозиторію — налаштувати GitHub Actions на `pytest` і `pytest-cov` без збереження `.env`.
