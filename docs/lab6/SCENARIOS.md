# Етап 4. Системне тестування через браузер

Базова адреса: `http://127.0.0.1:8001/`. Запуск серверу з `backend`:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

## API у DevTools
У Chrome натисни `F12 → Network → Fetch/XHR`. Під час входу перевір `POST /api/auth/login`, `Status 200` для успішного входу (або `401` для неправильного пароля). Не включай вкладку `Payload` з паролем у скриншот. Для каталогу перевір `GET /api/books`, `Status 200` і JSON-відповідь.

## Межі системного тестування
Автоматизовані `test_lab6_system.py` моделюють процеси через HTTP API та тестову SQLite. Це **не** тест браузерного JavaScript. Наведені ручні сценарії заповнюють прогалину: реальна робота HTML/CSS/JS з FastAPI та PostgreSQL. Для браузерної автоматизації можна згодом додати Playwright або Selenium, проте методичка дозволяє використовувати інші інструменти.
