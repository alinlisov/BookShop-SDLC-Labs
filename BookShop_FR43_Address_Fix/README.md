# ЛР №5 — виправлення FR-4.3 та посилення NFR-2.2

Це **доповнення до локального BookShop**, а не новий проєкт. Працює з версією після четвертого етапу й оновлення дизайну «Літера».

## Що додається

- `PATCH /api/auth/me/address` — збереження адреси **лише авторизованим користувачем**.
- `GET /api/auth/me` — тепер включає `address` (або `null`, якщо не заповнено).
- `profile.html` — форма для області й адреси доставки.
- `js/profile.js` — читання й збереження адреси через API.
- `js/modern-main.js` — автоматична підстановка області та адреси у форму замовлення.
- `backend/tests/test_profile_address.py` — три перевірки API, авторизації та AES-GCM.

**Міграції PostgreSQL не потрібно:** стовпець `users.address_encrypted` уже присутній у раніше підготовленій моделі. Ключі `.env` змінювати не треба! Не видаляй таблицю `users`.

## Встановлення

1. Зроби резервну копію проєкту, зупини FastAPI (`Ctrl+C`).
2. Розпакуй **усю** папку `BookShop_FR43_Address_Fix` у корінь `BookShop-SDLC-Labs` поруч із `backend`, `js`, `profile.html`.
3. Відкрий термінал PyCharm у корені репозиторію й виконай:

```powershell
.\backend\.venv\Scripts\python.exe .\BookShop_FR43_Address_Fix\apply_fr43.py
```

Якщо побачиш попередження про невідомі фрагменти, скрипт **нічого не змінить**. Тоді поточні файли відрізняються від вихідної версії і їх потрібно звірити.

4. Перевір тести:

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest -v
```

5. Запусти сайт:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

6. Відкрий `http://127.0.0.1:8001/login.html`, увійди, перейди в `profile.html`, вибери область, введи адресу, натисни **Зберегти адресу**. Далі відкрий `index.html#order`: область та адреса мають підставитися автоматично.
7. Онови сторінку профілю — адреса повинна залишитися. Перевір у pgAdmin `users.address_encrypted`: там повинен бути шифротекст, не відкрита адреса.

## Скриншоти для звіту

- Профіль: форма зі збереженою тестовою адресою.
- Форма замовлення: автоматично заповнена адреса після входу.
- pgAdmin: `users.address_encrypted` (сховай персональні дані).
- `pytest -v`: нові тести пройдено.

## Важливі зауваження

- Використовуй **вигадану** адресу для тестування.
- Ті самі ключі шифрування мають залишитися в `.env`.
- Скрипт створює `.fr43-address-backup-YYYYMMDD-HHMMSS` із попередніми файлами. Перенеси його за межі репозиторію перед комітом.
- Цей патч не переносить дані в хмару і не змінює GitHub Pages. Демонструй локально на порту `8001`.
- Якщо `users.address_encrypted` відсутній у реальній PostgreSQL, не видаляй таблицю: потрібно окремо підготувати безпечну міграцію.
