# Веб-застосунок "Магазин книжок"

## Опис проєкту
Цей веб-застосунок реалізує адаптивний інтерфейс онлайн-магазину книжок.  
Користувачі можуть:
- переглядати каталог книг з цінами та авторами,
- здійснювати пошук книг за назвою,
- обирати книги та заповнювати форму замовлення,
- залишати відгуки про книги,
- переглядати список жанрів та топ-3 авторів.

Інтерфейс адаптується під різні пристрої (десктоп, планшет, смартфон).

## Функціональні можливості
Каталог книг:
- Відображення карток книг з назвою, автором, жанром та ціною.
- Кнопка «Замовити» підставляє обрану книгу у форму замовлення і плавно прокручує до неї.
- Пошук книг
- Пошук за назвою книги з автоматичним фільтруванням.
- Пошук працює під час набору тексту (real-time) та за кнопкою «Пошук».

Замовлення:
- Форма замовлення з полями:
- Вибір книги,
- Кількість,
- Повне ім’я,
- Телефон,
- Email,
- Адреса доставки.
- Валідація полів (обов’язкові поля, формат номера телефону).
- Після відправки показується сповіщення про успішне замовлення.

Відгуки:
- Можливість залишати коментарі про книги.
- Нові відгуки додаються у верхню частину списку динамічно.
- Кнопка «Залишити відгук» відкриває/закриває форму.

Жанри:
- Розгортання та згортання списку книг за жанрами (Класика, Фантастика, Детектив, Філософія, Роман).
- Відображення опису жанру та прикладів книг.

Топ авторів і фаворити читачів:
- Список топ-3 авторів магазину.
- Перелік найпопулярніших книг за відгуками користувачів.

## План розвитку і удосконалення

Можливі напрями удосконалення інтерфейсу:
- Додати авторизацію та збереження замовлень користувача.
- Реалізувати корзину з динамічним підрахунком загальної суми.
- Додати фільтри за жанрами та цінами.
- Підключити базу даних для зберігання книг та відгуків.
- Покращити адаптивність на дуже маленьких екранах.
